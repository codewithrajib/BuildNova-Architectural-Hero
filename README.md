# BuildNova-Architectural-Hero
BuildNova is a high-end, minimalist hero section designed for modern architectural firms and creative studios. It focuses on bold typography and immersive visual storytelling.

## ✨ Design Highlights
* **Dynamic Typography:** Elegant use of serif and sans-serif fonts to highlight core values (Sustainable, Innovative, Visionary).
* **Glassmorphism Navigation:** A sleek, blurred navigation bar that adapts to any background.
* **Dual Call-to-Action:** Integrated buttons for "View Portfolio" and a "Watch Showreel" video trigger.
* **Full-Bleed Visuals:** Optimized for high-resolution architectural photography.

## 🛠️ Built With
* **HTML5:** Semantic structure.
* **CSS3:** Advanced positioning, flexbox, and backdrop-filters.
* **Google Fonts:** Utilizing 'Bormi' or similar premium typography.
